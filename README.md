# Sahasa

Sahasa is a smart vegetable waste reduction prototype for vegetable wholesalers in Sri Lankan Dedicated Economic Centres (DECs).

It helps users review inventory, sales, demand forecasts, purchasing recommendations, and waste information from one dashboard.

## Features

- Demo login screen
- Dashboard overview
- Inventory tracking
- Sales summaries and performance
- Demand forecasting
- Purchase recommendations
- Waste monitoring
- Reports and settings views
- English and Sinhala language toggle

## Run locally

No build tools or dependencies are required.

1. Open `index.html` in a web browser.
2. Select **Demo Account** or use the pre-filled login details.

## Project structure

- `index.html` - Main application page
- `css/style.css` - Application styles
- `js/app.js` - Dashboard interactions and page rendering
- `js/data.js` - Prototype data
- `js/language.js` - English and Sinhala translations
- `assets/` - Static assets

## Notes

This is a front-end academic research prototype. It uses sample data and does not connect to a backend or live market data.
